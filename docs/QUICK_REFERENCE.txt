🔧 KEY TECHNICAL SPECS:

Variable Naming:
  - Roads: regionName.toLowerCase().replace(/ /g, '_') + 'Roads'
  - Example: "Bakool" → bakoolRoads

Road Colors (OSM):
  - Motorway: #7c2d12 (dark brown)
  - Trunk: #dc2626 (dark red)
  - Primary: #ef4444 (bright red)
  - Secondary: #f97316 (orange)
  - Tertiary: #fbbf24 (yellow)
  - Residential: #cbd5e1 (light gray)
  - Track: #78716c (stone gray)

Files Structure:
  - roads_by_region_latest/{Region}_roads.js
  - Variable: window[regionName.toLowerCase().replace(/ /g, '_') + 'Roads']
